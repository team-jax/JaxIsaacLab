# JAX V2 손 — 압력 센서 정의와 실제 로봇 연결 (2026-11-04)

시뮬레이션에서 압력 센서를 어떻게 모델링했고 어디에 쓰는지, 실제 손에 달 때 무엇을 맞춰야 하는지 정리한 문서입니다.

- **기준 모델:** 센서 버전 최종 `v28f_ik/model_7075`, 책상 높이 대응 `v34_relret/model_7550`. 두 모델의 센서 정의는 같습니다.
- **코드:**
  - `v2_pad_sensor_grasp.py`: 센서 모델, `pad_forces()`, `sensor_readings()`
  - `v2_front_grasp_close.py`: 힘 균형 닫기
  - `v2_front_lift_rl.py`: 들기 완료 판정

---

## 1. 센서 개수와 위치

압력 센서는 6개입니다. 손가락 3개(손가락 1, 손가락 2, 엄지)의 **첫 마디와 끝마디 패드 면**에 하나씩 붙습니다.

| 번호 | 붙는 링크 | 손가락 | 마디 |
|---|---|---|---|
| 0 | `Finger_1_1` | 손가락 1 | 첫 마디 |
| 1 | `Finger_2_1` | 손가락 2 | 첫 마디 |
| 2 | `Finger_3_1` | 엄지 | 첫 마디 |
| 3 | `Finger_1_2` | 손가락 1 | 끝마디 |
| 4 | `Finger_2_2` | 손가락 2 | 끝마디 |
| 5 | `Finger_3_2` | 엄지 | 끝마디 |

이 순서는 모든 곳에서 같습니다: 정책 관측 37–42, `pad_forces()`, `handover_state.json`의 `pad_N`.

**패드 면 방향**
- 각 손가락 링크는 자기 좌표계의 +x 쪽으로 닫힙니다. 그래서 패드 면은 링크의 +x 쪽 면입니다.
- 실제 손에서도 **손가락이 닫히는 쪽(큐브에 닿는 안쪽 면)**에 붙이면 됩니다.

**실제로 쓰이는 센서**
- 지금 동작에서는 큐브를 **끝마디 3개(센서 3, 4, 5)**로 잡습니다. 첫 마디 센서(0, 1, 2)는 거의 0 N입니다.
- 그래도 정책 입력에 6개가 다 들어가므로 6개 모두 달아야 합니다.
- 첫 마디 센서가 늘 0으로 읽혀도 정상입니다.

## 2. 시뮬에서 재는 힘

`pad_forces()`:

1. 각 링크와 **큐브 사이의 접촉력만** 잽니다. 책상 등 다른 물체에 닿은 힘은 들어가지 않습니다.
2. 그 힘을 링크 좌표계로 바꾼 뒤 **패드에 수직인 성분**만 씁니다(값은 `−f_x`).
3. 음수(당기는 힘)는 0으로 자릅니다.
4. 단위는 N입니다.

옆면에 닿은 힘은 읽히지 않습니다. 실제 패드형 FSR도 패드 면을 누를 때만 반응하므로 같은 특성입니다.

**쥐고 있을 때 전형적인 값** (힘 균형 닫기가 끝난 뒤)

| 센서 | 값 |
|---|---|
| 손가락 1 끝마디 | 1.0–1.3 N |
| 손가락 2 끝마디 | 1.0–1.3 N |
| 엄지 끝마디 | 2.3–3.0 N |
| 첫 마디 3개 | 0 N |

## 3. 센서 출력 모델 (정책 입력용)

### 3.1 센서: Marveldex RA12P (FSR)

| 항목 | 값 |
|---|---|
| 측정 범위 | 5 gf – 4 kgf |
| 무부하 저항 | 무한대 (출력 0) |
| 출력 허용 오차 | 최대 ±20% (데이터시트) |

데이터시트 그래프에서 읽은 힘–저항 곡선입니다. 5 gf 점은 외삽한 값이고, 사이 값은 로그–로그 직선 보간합니다.

| 힘 (gf) | 5 | 55 | 100 | 165 | 260 | 350 | 470 | 590 | 750 | 975 | 1290 | 1585 | 1920 | 2465 | 3240 | 4000 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 저항 (kΩ) | 60 | 19.5 | 11.5 | 8.8 | 7.5 | 6.8 | 5.4 | 4.4 | 4.0 | 3.5 | 3.1 | 2.9 | 2.7 | 2.6 | 2.55 | 2.5 |

### 3.2 읽기 회로: 분압 + 10비트 ADC

```
 Vin ──[ RA12P (R) ]──┬── Vout → ADC (10비트)
                      │
                   [ Rc = 10 kΩ ]
                      │
                     GND
```

- 출력: `Vout / Vin = Rc / (R + Rc)`, Rc = **10 kΩ**
- 정책 입력값: `round(Vout/Vin × 1023) / 1023` → **0–1 사이 값**
- 5 gf(0.05 N) 미만이면 **정확히 0**입니다.

### 3.3 힘 → 정책 입력 환산표

| 힘 | gf | 저항 | Vout/Vin | ADC (0–1023) |
|---|---|---|---|---|
| 0.05 N 미만 | < 5 | 무한대 | 0 | **0** |
| 0.05 N | 5 | 59 kΩ | 0.144 | 147 |
| 0.1 N | 10 | 43 kΩ | 0.189 | 193 |
| 0.3 N (닿음 기준) | 31 | 25.7 kΩ | 0.280 | 287 |
| 0.5 N | 51 | 20.2 kΩ | 0.331 | 339 |
| 1.0 N | 102 | 11.4 kΩ | 0.468 | 478 |
| 1.2 N (손가락 쥘 때) | 122 | 10.3 kΩ | 0.492 | 503 |
| 2.0 N | 204 | 8.2 kΩ | 0.550 | 563 |
| 2.7 N (엄지 쥘 때) | 275 | 7.4 kΩ | 0.576 | 589 |
| 5 N | 510 | 5.0 kΩ | 0.666 | 681 |
| 10 N | 1020 | 3.4 kΩ | 0.744 | 762 |
| 39 N (최대) | 4000 | 2.5 kΩ | 0.800 | 818 |

0 N에서 5 gf로 넘어가는 순간 값이 0에서 0.144로 뜁니다. 무부하일 때 저항이 무한대인 FSR의 특성을 그대로 넣은 것입니다.

### 3.4 학습 때 넣은 센서 오차 (평가 때는 끔)

| 항목 | 값 |
|---|---|
| 센서별 이득 오차 | 에피소드마다 ×(0.8–1.2) 균일 분포 (데이터시트 ±20%) |
| 측정 잡음 | 스텝마다 표준편차 0.005 (하중이 걸린 센서에만) |
| 양자화 | 10비트 |

실제 센서가 이 범위 안에 들어오면 보정 없이도 정책이 견딥니다.

## 4. 센서 값을 쓰는 곳

| 쓰는 곳 | 쓰는 값 | 기준 | 주체 |
|---|---|---|---|
| **정책 관측 37–42** | 3장의 ADC 값 (0–1), 6개 | — | 학습된 정책 |
| **힘 균형 닫기** | 힘 N, 손가락별 (첫 마디 + 끝마디 합) | 닿음 0.3 N → 셋 다 닿으면 조임 | 스크립트 |
| **들기 완료 `lift_done`** | 힘 N, 끝마디 | 엄지 ≥ 0.3 N 그리고 (손가락 1 또는 2) ≥ 0.3 N | 스크립트 |
| `handover_state.json`의 `pad_N` | 힘 N, 6개 | — | 기록 |

### 4.1 힘 균형 닫기 (스크립트)

손가락 첫 관절만 움직이고, 둘째 관절은 0°로 고정합니다.

1. 세 손가락이 각각 **0.25 rad/s**로 닫힙니다.
2. 손가락 힘(첫 마디 + 끝마디)이 **0.3 N**에 닿으면 그 손가락은 0.3 N을 유지하며 기다립니다.
3. 셋 다 닿으면 목표 힘으로 조입니다.
   - 조임 합계 **S = 2.0 + 1.5 × a7 N** (a7은 정책 행동 7번, −1–1, 최소 0.3 N)
   - 목표: 손가락 1 = S/2, 손가락 2 = S/2, 엄지 = S. 엄지가 두 손가락과 마주 누르므로 힘이 맞춰집니다.
   - P 제어 0.003 rad/N, 스텝당 최대 0.25 rad/s.
4. 첫 관절 최대 각도: 손가락 +30°, 엄지 0° (엄지는 −30°에서 시작).

**실제 로봇에서는 이 닫기를 위해 센서 값을 N으로 바꿔야 합니다.** 정책 입력(ADC 값)과 별개입니다.

### 4.2 들기 완료 판정

0.5초 동안 아래 조건이 계속 맞으면 `lift_done`이 켜지고, 팀원 MuJoCo 모델로 넘깁니다.
- 팔이 ㄴ자에 도착
- 팔 정지 (관절 < 0.05°/스텝)
- 끝마디 압력: 엄지 ≥ 0.3 N 그리고 (손가락 1 또는 2) ≥ 0.3 N
- 큐브가 4 cm 이상 들림

## 5. 실제 손에 달 때 할 일

### 5.1 회로
- [ ] 센서 6개를 각각 **10 kΩ 분압 + 10비트 ADC**로 읽습니다.
  - 12비트 ADC라면 0–4095를 0–1023으로 줄이거나, 0–1로 정규화해서 넣으면 됩니다.
  - Rc를 바꾸면 3.3 환산표가 달라집니다. 반드시 10 kΩ을 쓰세요.
- [ ] 읽는 주기는 정책 주기 **60 Hz 이상**이어야 합니다.

### 5.2 부착
- [ ] 각 손가락의 첫 마디와 끝마디, **닫히는 쪽(안쪽) 면 중앙**에 붙입니다.
- [ ] 큐브가 닿는 부분이 센서 감지 영역에 들어오는지 확인합니다. 지금은 끝마디로 큐브를 잡습니다.

### 5.3 보정
- [ ] **ADC → N 보정표**를 만듭니다. 힘 균형 닫기와 들기 완료 판정에 필요합니다.
  - 각 센서에 0, 10, 50, 100, 200, 300, 500 g 추를 올려 ADC 값을 기록합니다.
  - 3.3 표와 비교해서 ±20% 안이면 정책 입력은 그대로 써도 됩니다.
  - N 변환은 센서별 측정값으로 보간합니다.
- [ ] 무부하일 때 ADC가 0 근처인지 확인합니다. 회로 잡음이 0.005(≈ 5/1023)를 넘으면 필터가 필요합니다.

### 5.4 정책에 넣는 순서 (관측 37–42)
```
[손가락1 첫마디, 손가락2 첫마디, 엄지 첫마디, 손가락1 끝마디, 손가락2 끝마디, 엄지 끝마디]
```
각 값은 0–1입니다(ADC / 1023).

## 6. 확인된 사항과 주의

- **센서를 빼면 동작이 안 됩니다.** 정책 입력만 0으로 바꾼 시험에서는 97% → 94%로 거의 그대로였습니다. 하지만 힘 균형 닫기가 N 단위 압력으로 멈출 시점을 정하므로, 센서 없이는 닫기가 동작하지 않습니다. 모터 토크로 힘을 추정하는 방법은 시뮬에서 0%였습니다.
- **책상 높이 대응 모델(7550)도 센서 정의가 같습니다.** 큐브 높이를 책상 기준으로 보는 것만 다릅니다.
- **큐브 재질:** PLA 출력, 5.5 cm, 55 g, 마찰 정지 1.2 / 동 1.0입니다. 실제 큐브의 마찰이 다르면 필요한 조임 힘이 달라집니다.
