### 3.2 경로 계산 (`v27_grid_probe.py` → `v27c_regrid.py`)

1. 경유점 6개마다, 큐브 이동 (dx, dy) 2 cm 격자(9 × 9)에서 손가락 끝 중점이 (dx, dy)만큼 가도록 IK를 풉니다. 손 롤·피치는 고정, 요는 자유, 어깨 롤은 0° 한계라 제외합니다.
2. **v27 → v27c 수정:** 처음에는 아래에서 올라오는 구간까지 x만큼 옮겨서, 먼 큐브(x −8)일 때 손이 책상 모서리 밑으로 들어가 **285 N** 충돌했습니다. x 이동은 손이 책상 위에 올라온 뒤(5 → 8 s) 0 → 100%로 램프하게 바꿨습니다 → 0.76 N.
3. 실행 중에는 격자 사이를 쌍선형 보간합니다(`grid_weights`). 책상 높이는 직선 근사 표를 그대로 씁니다.
4. 처짐 보정을 위치별로 재 봤지만(`v27_sag_probe.py`) ±2° 안에서 들쭉날쭉해서 쓰지 않았습니다.

| 10 (v27l) | → 4950 | 책상 위 끌림 속도 벌점 300 | 92% | 93% ((−8,−5) 처음 100%) |

**공통 설정:** `GL_CUBE_BOX=1 GL_START_NOISE_DEG=0.75 GL_RISE=8 GL_LATE=8 GL_REWARD_SCALE=0.02 GL_TABLE=3 GL_NO_VCLIP=1 GL_WRIST_RANGE=0.4`

### 3.5 알게 된 것

- **체인 성적 ≠ 파지 단독 성적.** 파지 단독은 정확한 사전 파지 자세에서 시작하지만, 체인에서는 팔 들기가 약 1° 어긋나게 도착합니다. 89% → 2/9인 경우도 있었습니다. 시작 자세 잡음(±0.75°)으로 줄였습니다.
- **먼 쪽에서 끌림:** 팔을 뻗은 자세에서 어깨·팔꿈치로 들면 손이 위보다 로봇 쪽으로 당겨집니다. (−3, 0)은 4초에 86 mm 오르고 23 mm 끌렸지만, (−8, +6)은 29 mm 오르고 56 mm 끌렸습니다. 위치·속도·책상 위 속도 벌점 세 가지 모두 학습 중 평균 끌림 33~40 mm를 못 바꿨습니다.
- **관절 개방의 부작용:** 6회차에 연 어깨 회전·팔뚝 회전·손목 좌우를 들면서 씁니다. 그래서 손이 옆으로 꺾입니다. `model_4675`는 손목 좌우 +14.5°, 손 방향 y 0.20 → 0.27이었습니다. 13회차에서 벌점으로 잡는 중입니다.
- **실패 위치가 번갈아 나타남:** 8~11회차 동안 (−8, −5)와 (+2, 0) 중 하나가 약해졌습니다.

## 4. 문제와 해결 모음

| 문제 | 원인 | 해결 |
|---|---|---|
| PPO가 "안 하기"로 붕괴 (닫기, 들기, 진입) | 벌점이 커서 행동을 안 하는 게 이득 | 동작은 스크립트·제어기로, 정책은 잔차만. 늦으면 벌점. 품질로 보상을 완전히 게이트하지 않기 |
| 학습 50~100회 뒤 붕괴 | 보상 규모 vs 가치 손실 클리핑 | 보상 × 0.02, 이어 학습 시 클리핑 끔 |
| 사전 파지에서 정책이 진입을 피함 | 손가락–책상 여유 2 mm + 탐색 잡음 | 경로는 스크립트, RL은 ±8° 잔차 |
| RotationBody 관측이 OOD | 학습 내내 고정값 | 관측에서 고정값으로 가림 (`pre_hide_scripted_obs`) |
| 손가락 끝마디 떨림 | 11 g 링크에 kp 180 | 손가락 kp 40 / kd 2 + armature 2e-4 |
| ㄴ자에서 내릴 때 책상 충돌 | 1 rad/s 한계로 내려옴 | 목표 속도 상한 0.7 rad/s, 이후 v18 아래에서 올라오는 경로 |
| 체인 전환 직후 손 튐 | 처진 실제 자세에서 섞기 시작 | 목표값에서 섞기 시작, 0.25 s 정지 확인 후 전환 |
| 먼 큐브에서 팔 들기 285 N | 올라오는 구간까지 x 이동 | x 이동은 5 s 이후에만 |
| 넓은 범위 팔 들기 잔차가 큐브를 밂 | 잔차 재학습 중 생긴 버릇 | ±2 cm 학습본(v25 1197) 유지 |
| 모음 영상이 2배 느림 | 60 fps 원본을 30 fps로 저장 | 원본 fps 그대로 (`montage.py`) |
| 학습 20배 느려짐 / 학습 후 CUDA unknown error | GPU P8 저클럭 / 드라이버 상태 | 재부팅. 짧은 학습으로 속도 확인 |
| 내 쉘이 죽음 (exit 144) | `pkill -f`가 자기 쉘과 일치 | PID로만 종료 |

## 7. 남은 과제

1. **옆으로 꺾임:** 13회차(관절 2/4/6 벌점) 결과 확인.
2. **큐브 끌림:** 보상만으로는 안 줄었습니다. 들기 방향을 자세에 맞춰 바꿔 주는 계산(IK 보조)을 넣을지는 사용자 허락이 필요합니다(들기는 RL만 원칙).
3. **(−8, −5)와 (+2, 0)이 번갈아 약함:** 회차마다 실패 위치가 바뀝니다.
4. **큐브 회전 10~15°:** 들 때 기울었다 돌아옵니다.
5. **범위 확장:** 큐브 회전(요) 무작위화는 아직 없습니다.

## 9. 작업 규칙 (사용자 지시)

- 답변은 항상 한국어.
- 들기는 강화학습만. IK 보조는 먼저 물을 것.
- 영상은 Isaac Lab RecordVideo로, 체크포인트 run 폴더 `videos/` 아래에. 여러 위치는 한 영상으로 모으기.
- 학습 중 렌더링 금지. 학습이 20배 느려지면 GPU 저클럭 → 재부팅.
- 프로세스는 PID로만 종료 (`pkill -f` 금지).
- 옛 로그는 지우지 않음. 커밋하지 않음.
- 스크립트인 부분과 학습인 부분을 정직하게 구분해 보고.
- "그만하라 할 때까지" 학습 → 평가 → 수정을 계속 반복. 체인 영상은 최고 기록을 넘을 때만.
