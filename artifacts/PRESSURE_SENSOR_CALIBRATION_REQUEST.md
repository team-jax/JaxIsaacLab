# 압력 센서 보정 요청

센서 6개를 손에 달기 **전에** 하나씩 보정해 주세요.
결과는 CSV로 주시면 됩니다.
정규화(정책에 넣을 값으로 바꾸는 일)는 제 쪽에서 코드로 처리합니다.

---

## 1. 회로

- 가능하면 센서마다 **10 kΩ 풀다운 분압**으로 연결해 주세요.

  ```
  Vin ──[ 센서 ]──┬── 출력 → ADC
                  │
              [ 10 kΩ ]
                  │
                 GND
  ```

- ADC는 몇 비트든 괜찮습니다. 실제 비트 수와 Vin 전압만 알려 주세요.
- 센서마다 번호를 붙여 주세요.

  | 번호 | 위치 |
  |---|---|
  | 0 | 손가락1 첫마디 |
  | 1 | 손가락2 첫마디 |
  | 2 | 엄지 첫마디 |
  | 3 | 손가락1 끝마디 |
  | 4 | 손가락2 끝마디 |
  | 5 | 엄지 끝마디 |

---

## 2. 추 올려서 재기 (센서마다)

1. 센서를 평평한 곳에 놓습니다.
2. 감지 영역보다 조금 작은 **평평한 받침**(동전, 고무 패드 등)을 센서 위에 올립니다.
3. 받침 위에 추를 올립니다. 무게는 아래 순서입니다.

   **0, 5, 10, 20, 50, 100, 200, 300, 500, 1000 g**

4. 무게마다 올리고 **2초 기다린 뒤** ADC 값을 기록합니다. FSR은 처음에 값이 조금씩 흘러서 기다려야 합니다.
5. 가벼운 것부터 무거운 순서로 한 번(up), 무거운 것부터 가벼운 순서로 한 번(down) 잽니다.
6. 5번을 **3번 반복**합니다.

---

## 3. 손에 붙인 뒤 확인

- 손가락이 아무것도 안 잡았을 때의 값을 **10초 동안** 기록해 주세요. 잡음 확인용입니다.
- 손가락으로 큐브(5.5 cm PLA)를 가볍게 쥐었을 때의 값도 기록해 주세요.

---

## 4. 보낼 파일

| 파일 | 열 |
|---|---|
| `sensor_calib.csv` | `sensor_id, weight_g, direction(up/down), trial, adc` |
| `idle.csv` | `sensor_id, t_s, adc` |
| `grip.csv` | `sensor_id, t_s, adc` |

메모로 같이 보내 주세요.

- ADC 비트 수
- Vin 전압
- 분압 저항 값 (10 kΩ이 아니면 실제 값)

---

## 받은 뒤 처리 (참고용)

1. 센서마다 **ADC → 힘(N)** 보정 곡선을 만듭니다. 이 값은 손가락 닫기와 들기 완료 판정(0.3 N 기준)에 씁니다.
2. 측정한 힘을 시뮬과 같은 공식으로 **정책 입력값(0–1)**으로 바꿉니다. 그래서 회로가 시뮬과 조금 달라도 괜찮습니다.
3. 센서별 오차가 ±20% 안인지, 무부하 잡음이 충분히 작은지 확인합니다.
