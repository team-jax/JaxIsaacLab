# 실물용 정책 파일 (2026-11-05)

## 파일 구성

학습한 신경망은 **2개**뿐입니다. 나머지 파일은 같은 신경망을 다른 형식으로 저장한 것이거나, 신경망이 아닌 조회표와 영상입니다.

| 파일 | 종류 | 내용 |
|---|---|---|
| `grasp_lift_13075.pt` / `.onnx` / `_meta.json` | 신경망 1 | **쥐고 드는 정책** (`v50_r3/model_13075`). 관측 43 → 행동 11 |
| `raise_v25_1197.pt` / `.onnx` / `_meta.json` | 신경망 2 | **팔 들어올리기 보정 정책** (`v25 model_1197`). 관측 54 → 행동 11 (앞 8개만 사용) |
| `pregrasp_grid_v49_basec.pt` / `_m3c` / `_p3c` | 조회표 | 큐브 위치별 들어올리기 경로·사전 파지 자세 보정값 (책상 높이 0 / −3 / +3 cm) |
| `video/` | 영상 | 시뮬레이션 체인 영상 (6절) |

- **신경망 하나에 파일이 3개인 이유**
  - `.pt`와 `.onnx`는 같은 모델을 형식만 바꿔 저장한 것입니다. 실행 환경에 맞는 것 하나만 쓰면 됩니다. PyTorch가 있으면 `.pt`, 없으면 `.onnx`(ONNX Runtime 등)를 씁니다.
  - `_meta.json`은 정규화 값과 입출력 설명을 적은 참고 파일입니다. 실행에는 필요 없습니다.
- **조회표는 학습한 모델이 아닙니다.**
  - 큐브 위치 격자마다 IK로 미리 풀어 둔 관절 보정값입니다. 격자는 기준 위치에서 앞뒤·좌우 ±20 cm, 2 cm 간격(21×21점)입니다.
  - 들어올리기 경로의 6개 시점마다 팔 관절 8개 값이 들어 있습니다. 마지막 시점이 사전 파지 자세입니다.
  - torch 텐서로 저장해서 확장자만 `.pt`입니다.
  - 책상 높이가 학습 기준과 같으면 `basec`만 씁니다. `m3c`와 `p3c`는 책상이 기준보다 낮거나 높을 때 그 차이만큼 섞어 쓰는 표입니다. 차이가 −3 / +3 cm이면 그 표와 같아집니다.
  - 표의 값은 기본 경로와 기본 사전 파지 자세에 **더하는 값**입니다. 기본 경로와 자세 자체는 아직 이 문서에 없고, 코드(`v2_arm_raise.py`, `v2_front_grasp_lift.py`)에 있습니다.

## 신경망 파일 쓰는 법

- `.pt`는 TorchScript 형식입니다. `torch.jit.load(path)`로 불러 `model(obs)`로 호출합니다. 입력 크기는 `(N, 43)` 또는 `(N, 54)`이고, 반환값은 `(N, 11)`입니다.
- 관측 정규화는 파일 안에 들어 있습니다. 식은 `(x − 평균) / (표준편차 + 0.01)`이고, 값은 `_meta.json`에도 적어 두었습니다.
- 반환값은 확률 분포의 평균(결정적 행동)입니다. 쓰기 전에 **±1로 자르고** 아래 필터를 거칩니다.
- 원래 체크포인트와 출력이 같은지 확인했습니다(차이 0).

## 1. 쥐고 드는 정책 — 관측 43개

시뮬레이션은 60 Hz(1/60 s)로 돌았습니다. 각 값은 ±5로 자릅니다.

| 번호 | 내용 | 변환 |
|---|---|---|
| 0–13 | 관절 위치 14개 (Isaac 관절 순서) | `2·(q − 하한)/(상한 − 하한) − 1` |
| 14–27 | 관절 속도 14개 | rad/s × 0.2 |
| 28–30 | 큐브 위치, 로봇 베이스 좌표계 (m) | **29번에서 0.115를 뺍니다.** 책상을 로봇 쪽으로 옮기기 전 배치 기준으로 학습했기 때문입니다. |
| 31–33 | 큐브 속도, 베이스 좌표계 (m/s) | — |
| 34–36 | 큐브 위치 − 손끝 중점 (m) | 손끝 중점 = 끝마디 3개 링크 원점의 평균 |
| 37–42 | 압력 센서 6개 (첫 마디 1·2·엄지, 끝마디 1·2·엄지) | RA12P + 10 kΩ 분압 + 10비트 ADC 값 (0–1) |

- **9번(RotationBody 위치)** 에는 실제 값 대신 −155°에 해당하는 고정값을 넣습니다.
- **23번(RotationBody 속도)** 은 0을 넣습니다.
- 관절 순서와 한계는 `artifacts/SPEC_joints_sensors_2026-11-04.md` 2.1–2.2를 따릅니다.

## 2. 쥐고 드는 정책 — 행동 11개

**후처리:** `a = clip(출력, −1, 1)`을 구한 뒤, `a_used = 0.25·a + 0.75·a_used(이전)`로 거릅니다.

| 번호 | 의미 |
|---|---|
| 0 | 손끝 중점의 위아래 속도 = **−0.035·a0 m/s** (음수가 위) |
| 3 | 손끝 중점의 x 속도 = 0.005·a3 m/s (월드) |
| 5 | 손끝 중점의 y 속도 = 0.005·a5 m/s (월드) |
| 7 | 손가락 쪽 조임 목표 S_f = 5 + 4·a7 N. 손가락 1·2가 반씩 나눔 |
| 8 | 손가락 1·2 끝마디 굽힘 = 60°·clamp(a8, 0, 1) |
| 9 | 엄지 조임 목표 S_t = 5 + 4·a9 N |
| 10 | 엄지 끝마디 굽힘 = 60°·clamp(a10, 0, 1) |
| 1, 2, 4, 6 | 쓰지 않음 |

**행동 0·3·5를 관절로 바꾸는 IK (스크립트):**
- 손끝 중점 속도 명령을 DLS 야코비안으로 팔 관절 속도로 바꿉니다.
- 쓰는 관절: 어깨 피치, 어깨 요, 팔꿈치, 아래팔, 손목 피치, 손목 요.
- 손 방향은 들기 시작 때 방향을 유지합니다.
- 설정값: 감쇠 0.02, 관절당 최대 0.6 rad/s, 위치 되먹임 이득 2/s.

## 3. 정책 밖에서 스크립트로 하는 일 (실물 제어 코드로 옮겨야 함)

1. **팔 들어올리기 (0–8 s)**
   - 스크립트 경로를 따라갑니다. 경로는 큐브 위치로 `pregrasp_grid_v49_*` 격자를 조회해서 얻습니다.
   - 여기에 `raise_v25_1197` 출력 0–7번 × ±8°를 관절 보정으로 더합니다.
2. **사전 파지 손 위치**
   - 격자 조회 위치를 큐브보다 **2.5 cm 깊게**(x −0.025 m) 잡습니다.
   - 손목 요 관절에 **+12°** 굴림을 더합니다.
3. **손가락 닫기 (힘 제어)**
   - 첫 관절만 닫습니다.
   - 세 손가락이 모두 0.3 N 이상 닿을 때까지 기다립니다.
   - 그다음 손가락별 (첫 마디 + 끝마디) 힘을 조임 목표에 맞춥니다. 목표는 손가락 1·2가 각각 S_f/2, 엄지가 S_t입니다.
   - 첫 관절 상한: 손가락 30°, 엄지 0° (엄지는 −30°에서 시작).
4. **ㄴ자 복귀**
   - 큐브가 4 cm 이상 들린 상태가 0.5 s 이어지면 시작합니다.
   - 2.5 s smoothstep으로 ㄴ자 자세로 갑니다. 목표 관절값: 1.9, 0, 7.2, 92.1, 0, −1.9, −0.2°.
   - 행동 7–10은 복귀 시작 때 값으로 고정합니다.
5. **완료 판정**
   - ㄴ자에 도착하고, 관절이 멈춰 있고(< 3°/s), 큐브가 4 cm 이상 들린 상태여야 합니다.
   - 엄지 (첫 마디 + 끝마디) ≥ 0.3 N, 그리고 손가락 1 또는 2 (첫 마디 + 끝마디) ≥ 0.3 N이어야 합니다.
   - 이 상태가 0.5 s 이어지면 완료로 보고 팀원 모델에 넘깁니다.

## 5. 실물에서 먼저 확인할 것

- 관절 0°와 회전 방향이 URDF와 같은지.
- 실제 명령 지연. 학습 범위는 0–67 ms입니다.
- 모터 게인. 학습 범위는 시뮬 대비 ×0.6–1.5입니다.
- 압력 센서 ADC → N 보정. 닫기와 완료 판정은 N 단위를 씁니다.
- 큐브와 패드 사이의 마찰. 0.3보다 낮으면 위험합니다.
- 카메라로 잰 큐브 위치의 오차. 학습 범위는 ±5 mm입니다.
